# M1 阅读器 + 摘录：实现状态

分支 `m1-reader`。验收用例：[UC-01](usecases/UC-01-excerpt-to-mindmap.md)，测试论文 arXiv:2610.18579v1（33 页、双栏）。
设计依据：mNote 正式版设计稿「页边」（暖纸底、衬线、页边卡片 + 常驻脑图 + 底部四模式工具条 + 夜读）。

## 代码结构（全部新增在 `lib/mnote/`，对 Saber 原有代码的改动只有 3 处）
| 文件 | 作用 |
|---|---|
| `model/models.dart` | 学习集 / 文档 / 卡片数据模型，JSON 序列化；四色语义（定义/实验证据/应用/易错，日夜两套色值） |
| `model/text_clean.dart` | 摘录文本清洗：合并 PDF 换行、去断词连字符（含 PDFium 的 U+0002 标记）、中英文分别处理；默认卡片标题 |
| `store/study_store.dart` | 本地持久化（应用目录 `mnote/sets/<id>/set.json`，PDF 复制进 `docs/`，框选截图进 `images/`），原子写入、防抖保存、删除可撤销、防止把卡片拖进自己的子树 |
| `reader/workspace_page.dart` | 三栏工作区：PDF（pdfrx）｜页边栏｜脑图；摘录菜单、高亮绘制、框选截图、卡片飞入动效、回到原文闪烁、目录、搜索、夜读 |
| `reader/pdf_geometry.dart` | 选区 → 按行的高亮矩形；页面坐标 ↔ 视图坐标；跳转到卡片 |
| `reader/margin_rail.dart` | 页边卡片排布（与原文同高、互不重叠）与虚线引线 |
| `reader/excerpt_menu.dart`、`mode_toolbar.dart`、`reader_search.dart` | 摘录菜单、底部四模式工具条、全文搜索面板 |
| `mindmap/mindmap_view.dart` | 横向脑图：长按拖到另一张卡片上成为子卡片、拖到根节点回到第一层；自动缩放适配面板宽度 |
| `cards/card_detail_panel.dart` | 卡片详情：标题、原文/截图、出处、颜色、批注、标签、子卡片、删除 |
| `bookshelf/bookshelf_page.dart` | 书架（学习集列表）、学习集页（文档列表、导入 PDF） |

Saber 原有代码的改动：`lib/pages/home/home.dart`、`lib/data/routes.dart` 增加第一个底部标签「学习集」；`lib/main.dart` 启动页改为学习集。

## 测试
- `test/mnote/mnote_unit_test.dart`：文本清洗、默认标题、页边排布、存储（建集、导入、增删改、撤销、重新加载）
- `test/mnote/arxiv_excerpt_test.dart`：用真实论文验证第 4、5、8、10、12 步的文本与位置
- `test/mnote/mnote_widget_test.dart`：摘录菜单、脑图拖拽改层级、模式切换替换工具组
- `test/mnote/workspace_smoke_test.dart`：1280×800 下渲染整个工作区（真实 PDF + 卡片），检查三栏、页边卡片、收起/展开脑图、框选层，无异常
- `test/mnote/workspace_screenshot_test.dart`：生成截图 `test/mnote/screenshots/`，默认跳过，`MNOTE_SCREENSHOTS=1 flutter test --update-goldens test/mnote/workspace_screenshot_test.dart`

全量测试：与 `m0-setup` 相比，唯一的新增失败是 4 个 Saber 应用商店截图对比（`screenshot_goldens_test` 的 1_home、4_settings），原因是底部多了「学习集」标签；没有重新生成，因为测试环境没有中文字体，会把方块字写进商店截图。首页相关的 10 个 golden 已按新标签更新；`home_subpage_transition_test` 改为从「最近」页开始。
