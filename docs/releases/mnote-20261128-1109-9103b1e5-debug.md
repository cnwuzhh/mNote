# 本次改进

## 新功能
- **删除文档**：学习集页长按文档，菜单里选「删除文档」（原来长按直接是重命名，现在菜单里有「重命名」「删除文档」两项）。
  - 确认框写明会一起删除的内容：从这份 PDF 摘录的卡片、仅高亮、手写笔迹、翻译 / 解释（用户选择的方案 1：卡片随文档删除）。
  - 其他文档的卡片保留；原来挂在被删卡片下的，上移到最近的保留下来的上级（没有就到根节点）。
  - 删除后约 8 秒内可「撤销」，完整恢复（包括脑图层级）；PDF、笔迹和被删卡片的截图在撤销期过后才真正删除；App 切到后台时立即完成删除。
  - 已登录 Nextcloud 时，这些文件在服务器上也标记删除。
