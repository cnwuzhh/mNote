# 本次改进

## 新功能 / 修复（RESULTS-NEXTCLOUD 报告）
- **学习集纳入 Nextcloud 同步**（报告「失败 1」）：之前只同步 Saber 原有的白板笔记，学习集、PDF、卡片、AI 标记、笔迹都只在本机。现在学习集数据放在 Saber 数据目录下的隐藏文件夹 `.mnote/`，由 Saber 现有的同步（路径和内容端到端加密）上传和下载：
  - 第一次运行本版本时，自动把旧位置的学习集迁移过去（同一磁盘直接移动，否则复制后删除旧的）；
  - 学习集、导入的 PDF、截图、笔迹保存后自动加入上传队列；设备相关的设置（如「手指书写」）不同步；
  - 从服务器下载到的学习集自动出现或更新（打开着的页面也会更新）；在另一台设备删除的学习集会消失；
  - 删除学习集时，服务器上的对应文件也标记删除；
  - 临时文件（写入中的 `.tmp`、下载中的 `.part`、损坏备份 `.corrupt-…`）不上传；
  - Saber 的笔记列表不显示 `.mnote` 文件夹。
- **远端目录已存在时报 405**（报告「失败 2」）：登录后下载和上传两个同步流程同时发现远端 `/mNote` 不存在，都去创建；后一个收到「已存在」(405) 后异常退出，下载扫描中断。现在 405 视为已存在，重新列出后继续（只重试一次）。

## 同时包含（上一次未打包成功的修复）


### 数据文件夹无法写入时的提示（BUG-WIN-01）
- **BUG-WIN-01：新建学习集没有反应**（Windows 免安装版，测试 Agent 报告）：在数据文件夹无法写入时（这次是在只允许写工作区的受控环境里运行，`AppData\\Roaming\\cnwuzhh\\mNote` 被「拒绝访问」），点「确定」后对话框关闭、什么都没发生，也没有提示。原因：新学习集先加入列表、再保存；保存失败的错误没有人处理，列表也没有刷新。现在：
  - 保存失败时不显示这个学习集，并弹出「无法新建学习集」，写明原因和文件夹路径；
  - 启动时数据文件夹打不开：学习集页显示原因、路径和「重试」（失败不再被记住，重试会真的重新打开）；
  - 之后保存失败（编辑卡片、阅读位置等）：学习集页顶部出现红色「保存失败：…」提示条，阅读界面弹出提示；保存恢复正常后提示消失。
- 这个修复让问题「看得见」；在普通 Windows 用户会话里数据文件夹本来就可以写入，Windows 版的功能仍需在普通环境里测一遍（TC-WIN-01 第 6 步）。
