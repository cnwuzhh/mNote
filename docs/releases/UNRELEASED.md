> 阅读体验第一批：引用预览、划词翻译与解释（AI）、沉浸阅读与护眼纸色、卡片浮层不挡正文

# 本次改进

## 新功能（UC-03，设计稿 design/reading-v1）
- **引用与链接预览**：点正文里的引用（作者名或年份）、「Figure / Table」编号、「§」章节号，原地弹出预览——参考文献显示该条目原文（可复制），图表和章节显示目标区域；「跳过去」后左下角有「返回第 N 页」。外部链接可在浏览器打开或复制。依据 PDF 自带的链接目标。
- **划词翻译与解释（AI）**：摘录菜单新增「翻译」「解释」（「复制」收进「更多」）。结果第一次自动展开在句子上方、逐字出现；点页面别处收成句旁的「译」「释」标记（句子加虚下划线），点标记再展开、不重新请求；可存为卡片批注、摘录为卡片（附译文）、复制、重新生成、删除；一键隐藏全部标记，长按标记删除。结果随学习集保存。标注「AI 生成 · 服务名 · 可能有误」。
- **AI 服务设置**（学习集列表右上角）：导入配置文件（与 ai_providers.json 同格式），API Key 存系统加密存储、只显示后 4 位；测试连接；「翻译后只显示标记（不自动展开）」；清除配置。默认服务出错或返回空结果时自动换用备用服务。学习集页右上角可关闭本学习集的 AI。
- **沉浸阅读**：用手指向下读时顶栏和工具条收起，轻点页面恢复；程序发起的跳转不会触发。
- **三档主题**：日间 / 护眼纸色 / 夜读（顶栏主题按钮）；护眼纸色把界面和 PDF 页面都染成暖纸色。
- **卡片浮层不挡正文**：打开卡片浮层时 PDF 向左平移，让右栏露在浮层左边，关闭时移回；浮层打开时仍可拖动 PDF。

## 修复
- 整理模式的原文侧滑页：只摘了一个词的卡片会放大到只剩几个字母——现在至少显示原文所在的整栏。
- 整理模式打开原文侧滑页时脑图被遮住——现在脑图自动缩放到侧滑页左边。
