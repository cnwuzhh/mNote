> 从网络链接导入 PDF（支持 arXiv 论文页链接）

# 本次改进

## 新功能
- **从网络链接导入 PDF**：学习集页「导入 PDF」改为两个选项「从本机选择」「从网络链接」。
  - 粘贴链接后下载，显示进度条（已下载 / 总大小），可随时取消；下载好的 PDF 保存进学习集，离线也能读。
  - arXiv 论文页链接（如 `arxiv.org/abs/2610.18579v1`）自动换成对应的 PDF；不写 `https://` 也可以。
  - 文档标题优先用服务器给出的文件名，否则用链接里的文件名。
  - 文档记住来源链接，学习集页上显示「来自 …」。
  - 剪贴板里有链接时，输入框自动填入。
  - 出错时给出原因：连不上（如「无法连接到 …」）、服务器错误（含状态码）、「这个链接不是 PDF」（下载内容开头不是 PDF 标记）、文件超过 200 MB、长时间没有数据。出错或取消都不留下半个文件。
- **文档重命名**：在学习集页长按文档即可改标题（本地导入的文档也适用）。

## 测试
- 新增自动化测试：`url_import_test.dart`（13 项，用本地 HTTP 服务器覆盖正常下载与进度、arXiv 转换、各种链接格式、文件名解析含中文、重定向、非 PDF、404、超过大小、取消、连接停滞、连不上、来源链接持久化）；`url_import_ui_test.dart`（3 项，界面流程：选「从网络链接」→ 输入 → 下载 → 文档出现并显示来源 → 长按重命名；非 PDF 报错；格式不对的链接在对话框内提示）。
- 新增真机用例 `cases/TC-60-url-import.md`：TC-URL-01 至 TC-URL-09；TC-URL-01 加入冒烟。

## 已知问题
- 不支持需要登录才能下载的链接，也不支持从浏览器「分享到 mNote」直接导入（后续可做）。
- 下载走系统网络；如果所在网络需要手动设置代理才能访问外网，目前不会使用该代理。
- 同一个链接导入两次会得到两份文档（不去重）。
- 其余同上一编译。
