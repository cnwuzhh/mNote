# 本次改进

## 新功能
- **手写模式**（底部工具条「手写」）：钢笔、荧光笔、橡皮、套索；细/中/粗三档；每种笔四个颜色；撤销、重做。
  - 默认只有触控笔能写，手指照常滚动和缩放；「手指书写」开关打开后手指也能写（此时手指不再滚动）。开关状态会记住。
  - 笔迹属于 PDF 页面，跟着滚动和缩放；按页保存在学习集里（`files/mnote/sets/<学习集>/ink/<文档>.ink.bson`），不改动原 PDF 文件。
  - 荧光笔用「变暗」混合，压在文字上时文字仍保持黑色清晰（夜读模式下用「变亮」）。
  - 触控笔的橡皮端（如果有）直接擦除。
  - 笔迹使用 Saber 的笔迹引擎（压感、平滑），格式与 Saber 笔记一致。
- **套索摘录**：用套索圈住笔迹，菜单「摘录为卡片 / 删除 / 取消」。摘录为卡片会把圈选范围内的原文和笔迹截成图片卡片，放进页边和脑图，可回到原文。
- **导出**（顶栏「导出」图标）：生成带摘录高亮和手写的 PDF，并打开系统分享。导出是图片式的（每页约 144 dpi），不能在导出的文件里选字；原文件不变。服务器上测得 33 页论文约 14 MB、7.5 秒，平板上会更慢。
- 手写模式下，四个模式按钮收成一个「手写 ▾」菜单，工具改为图标（名称在长按提示里），这样整组工具在横屏下放得下。

## 修复
- 打开文档的一瞬间，PDF 已加载但页面布局还没算好时，页边卡片计算位置会报错（自动化截图测试中出现，真机上重新打开文档时可能遇到）。
- 两个 Nextcloud 同步测试原来会用 Saber 的公共测试账号登录 **Saber 官方服务器**并上传测试文件；改为只在配置了自己的测试服务器时运行（环境变量 `MNOTE_TEST_NC_URL / _USER / _PASSWORD / _ENC`），否则跳过。

## 已知问题
- 打开「手指书写」后，双指不能滚动或缩放；需要滚动时先关掉开关。
- 一笔跨页时，整笔属于起笔所在的页（另一页上显示的部分其实画在前一页的范围外）。
- 导出的 PDF 不保留可选中的文字；文件较大。
- 套索只选手写，不选摘录高亮。
- 笔迹暂不同步到 Nextcloud。
- 上一个编译的已知问题仍在（图标、隐私政策为占位地址、竖屏布局等）。
