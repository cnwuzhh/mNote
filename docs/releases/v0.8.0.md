mNote 是面向安卓平板（以及 Windows 电脑）的论文阅读与学习 App，与 MarginNote 的工作方式相似：读 PDF、摘录成卡片、用脑图整理、回忆复习。基于 [Saber](https://github.com/saber-notes/saber)（GPL-3.0）。

这是第一个公开版本（0.8.0，预发布）：主要功能都已可用并有自动化测试，部分功能还在真机测试中。

## 主要功能

**阅读**
- PDF 铺满屏幕阅读；右侧窄边栏显示卡片数和与原文同高的彩色细条，卡片和脑图以浮层拉出，不挤压正文（打开卡片浮层时正文自动平移，不被挡住）。
- 点引用、图表编号、章节号原地预览（参考文献原文、图、章节开头），跳过去后可「返回第 N 页」；外部链接可在浏览器打开。
- 沉浸阅读：向下读时顶栏和工具条自动收起，轻点恢复。
- 日间 / 护眼纸色 / 夜读三种主题。
- 目录、全文搜索、导出带标注的 PDF。

**摘录与整理**
- 选中文字摘录为卡片（四种颜色：定义、实验证据、应用、易错），或框选图片区域；摘录后提示「已加入」，可编辑、撤销。
- 手写：钢笔、荧光笔、橡皮、套索（把手写圈成卡片），触控笔书写、手指滚动。
- 整理模式：脑图铺满屏幕，拖动节点调整层级；「回到原文」在侧边显示原文段落。
- 回忆模式：遮住卡片内容，点一下揭开。

**AI 翻译与解释**（需要自己的 AI 服务）
- 选中一句点「翻译」或「解释」，结果在句子上方展开，收起后变成句旁的「译」「释」标记，点开再看，随学习集保存。
- 支持 OpenAI 兼容接口；在「AI 服务」里导入配置文件，API Key 保存在系统加密存储中；默认服务失败时自动换用备用服务；每个学习集可单独关闭 AI。

**文档与数据**
- 从本机或网络链接导入 PDF（arXiv 论文页链接会自动换成 PDF）。
- 长按文档可重命名、删除（连同从它摘录的卡片，8 秒内可撤销）。
- Nextcloud 同步：学习集、PDF、卡片、笔迹、翻译标记随 Saber 的端到端加密同步上传和恢复。
- 数据保存加固：原子写入、损坏文件隔离备份、无法写入时明确提示。

## 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| Android（arm64） | `mNote_v0.8.0_…_arm64.apk` | 用 mNote 的正式密钥签名。**如果附件里没有 APK**：仓库尚未配置正式签名密钥，会在配置后补上 |
| Windows 10/11（x64） | `mNote-Windows-v0.8.0-installer.exe` | 安装程序（可选安装 Visual C++ 运行库） |
| Windows 10/11（x64） | `mNote-Windows-v0.8.0-portable.zip` | 免安装版：解压后运行 `mnote.exe` |

Windows 版本未做代码签名：首次运行时 Windows 可能提示「已保护你的电脑」，选「更多信息」→「仍要运行」。校验值见 `SHA256SUMS-windows.txt`。

## 已知问题

- 同一个学习集在两台设备上同时修改时，以后保存的那一份为准（Nextcloud 同步尚无合并）。
- 没有内部链接的 PDF（如扫描件）不能预览引用；扫描版 PDF 不能选字摘录。
- Windows 版按平板界面设计：脑图节点要长按约半秒才能拖动，暂无快捷键和右键菜单。
- AI 结果可能有误（界面已标注）。
- 尚未实现：页面缩略图与书签、双页 / 单栏视图、间隔复习（FSRS）。
