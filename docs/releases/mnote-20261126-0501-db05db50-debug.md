# 本次改进

> 首个附带测试说明的编译。没有上一个打包版本，下面汇总到目前为止的全部改动。

## 新功能
- **学习集书架**（App 打开后的第一个标签「学习集」）：新建、重命名、删除学习集；在学习集里导入 PDF。
- **三栏阅读工作区**：左侧 PDF 连续阅读，中间页边栏，右侧常驻脑图；脑图可收起、可拖动分隔条调宽；屏宽不足 1000 时脑图自动收起。
- **摘录**：选中文字弹出菜单（定义 / 实验证据 / 应用 / 易错 四色，摘录为卡片、仅高亮、复制）；卡片停在原文同一高度的页边，并用虚线连到高亮；新卡片飞入脑图。摘录文字自动合并换行、拼回行尾断开的单词。
- **框选**：在页面上拖出矩形，截成图片卡片。
- **脑图**：长按拖动卡片调整层级；点卡片上的图标回到原文并闪烁；树太宽时自动缩小。
- **卡片详情**：标题、原文或截图、出处、颜色、批注、标签、子卡片；删除可撤销。
- **目录**（读取 PDF 书签）、**全文搜索**、**夜读模式**。
- 所有学习集数据保存在本机，退出后再打开会回到上次的阅读位置。

## 去掉 Saber 痕迹
- App 名、包名改为 mNote（`io.github.cnwuzhh.mnote`），可与 Saber 同时安装。
- 界面文字中的 Saber 全部改为 mNote（28 种语言）；关于页版权改为「mNote（基于 Saber）」并保留原作者署名。
- 删除首页欢迎页。
- 关闭崩溃报告（原来会发到 Saber 作者的 Sentry），不再弹授权窗口，设置里去掉对应开关。
- 登录页去掉「Saber 的 Nextcloud 服务器」，只保留「其他 Nextcloud 服务器」。
- 去掉关于页的赞助按钮；存图相册名、连接服务器的客户端标识改为 mNote。
- 数据文件夹从 `Saber` 改名为 `mNote`（本机首次启动自动迁移；Nextcloud 上新建 `mNote` 文件夹）。

## 修复
- 登录页：输入 `http://localhost:8380` 这类不带点的地址时，登录按钮一直是灰色。
- 横屏登录页弹出键盘后底部溢出（黄黑条纹）。
- 卡片详情里改颜色后，PDF 上的高亮要等滚动后才变色。

## 已知问题
- App 图标仍是 Saber 的。
- 隐私政策链接仍指向 Saber 网站。
- 手写、整理、回忆三个模式只有工具条占位。
- 竖屏没有专用布局；在图片上长按时不会提示改用框选。
- 搜索：词恰好在行尾断开时可能搜不到。
- 待复习数固定为 0（复习功能在后续里程碑）。
- 界面文字直接写的中文，未接入多语言。
- versionName 仍是上游的 1.38.0，请以编译编号区分版本。
