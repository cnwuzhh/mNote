# 本次改进

## 新功能 / 改动
- **阅读时以阅读为主**（设计稿 `design/layout-v2/layout-compare.html` 方案 D）：
  - 去掉三栏。摘录、手写模式下 PDF 占满宽度：1280 宽横屏上阅读区约 1236 dp、页面约 1200 dp（原来约 620），论文正文显示大小约为原来的 1.9 倍。
  - 右侧 44 dp **窄边栏**：卡片数、「卡片」「脑图」入口、与原文同高的彩色细条；可「收起边栏」成屏幕边的小把手。
  - **卡片浮层 / 脑图浮层**：点入口或从窄边栏向左划拉出，盖在 PDF 右侧，PDF 不移动、不重排；卡片与原文同高，屏幕外的卡片显示「↑ 上方 n 张」「↓ 下方 n 张」，点一下跳过去；浮层内可在卡片 / 脑图之间切换；点浮层外收起。
  - **摘录反馈**：摘录（文字、框选、套索）后选区旁显示「已加入：标题　编辑　撤销」约 3 秒，卡片飞入窄边栏对应高度。
- **整理模式**（之前是「后续版本」）：脑图铺满屏幕、居中放大；拖拽调整层级；点「回到原文」不离开脑图，右侧滑出原文侧滑页，放大显示该卡片所在段落并高亮，「去阅读」切回阅读并跳到原文。「合并」「大纲」「自动排版」仍为后续版本。
- **回忆模式**（之前是「后续版本」）：脑图上卡片内容被灰条遮住，点一下揭开；「全部揭示」「重新遮挡」；顶栏显示未揭开数量。「开始复习」（间隔重复）为后续版本。
- 工具条最左改为一个「模式」按钮（显示当前模式，点开菜单切换），所有模式下工具组都放得下。
- 提示条（如「在页面上拖出一个矩形来截取区域」「已删除…」）改为浮在工具条上方，不再盖住工具条。
