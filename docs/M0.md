# M0 基础整理

## 变更
- **包名 / applicationId**：`com.adilhanney.saber` → `io.github.cnwuzhh.mnote`（Kotlin 包与 `MainActivity` 同步迁移），可与 Saber 共存安装。
- **剪贴板 Provider authority** 改为 `io.github.cnwuzhh.mnote.SuperClipboardDataProvider`，避免与已安装的 Saber 冲突导致安装失败。
- **显示名**：Android `android:label` 与 Flutter `MaterialApp.title` 改为 `mNote`。
- **链接指向本仓库**：检查更新（version.dart / releases API / changelog）、License、Releases 链接改为 `cnwuzhh/mNote`，避免 mNote 提示用户“更新到 Saber”。
- **签名**：release 构建读取 `android/key.properties`（已在 .gitignore 中）；没有该文件时回退到仓库里的 `fallback-key.properties`（仅供测试）。
  - 正式证书：`CN=mNote, O=cnwuzhh, C=CN`，RSA 4096，有效期 10000 天
  - SHA-256：`E3:21:3D:0E:C5:88:A6:ED:31:7A:B1:79:9B:B1:9B:28:EA:07:A8:99:9A:F2:F1:E0:10:29:71:86:DB:CE:7B:CC`
  - 证书与密码**不入库**，位于构建服务器 `~/mnote-release/`。**证书丢失将无法再覆盖更新已安装的 App，请异地备份。**
- **CI**：新增 `.github/workflows/mnote-android.yml`（push main / `m*-*` 分支 / PR / `v*` 标签）：分析 → 回归测试 → 构建 arm64 release APK → 上传 artifact（打 tag 时附到 Release）。
  - 配置以下 secrets 后用正式证书签名，否则用 fallback 测试签名：`MNOTE_KEYSTORE_BASE64`（`base64 -w0 mnote-release.jks`）、`MNOTE_STORE_PASSWORD`、`MNOTE_KEY_PASSWORD`、`MNOTE_KEY_ALIAS`（`mnote`）。
  - 上游 `android.yml`（含 Play 商店上传）改为仅手动触发。

## 验证
- `flutter build apk --release --split-per-abi --target-platform android-arm64` 通过；`aapt2` 确认 package=`io.github.cnwuzhh.mnote`、label=`mNote`；`apksigner` 确认为上述正式证书。
- `test/login_keyboard_overflow_test.dart`、`test/version_test.dart` 通过。

## 待办 / 注意
- **图标**：仍为 Saber 图标，待设计方向确定后替换。
- 已安装的旧版（`com.adilhanney.saber` 包名、fallback 签名）是另一个 App，需手动卸载，数据不会自动迁移。
- 新 CI 尚未在 GitHub 上实际跑过；Saber 其它平台工作流（iOS/macOS/Windows/Linux/Snap 等）未改，在本仓库可能失败。
- iOS / macOS / Linux / Windows 的 bundle id 与显示名未改（目前只做 Android）。
- 登录回调 scheme `nc://` 与 Saber 相同，两者都装时系统可能弹出选择框。
- 隐私政策链接、默认 Nextcloud 服务器仍为 Saber 官方。
