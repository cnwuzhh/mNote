# UC-02 在 PDF 上手写批注（「处理 PDF」阶段核心用例）

> **布局更新（v2，2026-11-26）**：工作区不再是三栏。阅读（摘录 / 手写）时 PDF 占满宽度，右侧只有窄边栏（卡片数、卡片 / 脑图入口、与原文同高的彩色细条，可收起成把手）；卡片列表和脑图都以浮层从右侧拉出，盖在 PDF 上，PDF 不移动；摘录后选区旁显示「已加入：标题　编辑　撤销」，卡片飞入窄边栏。整理模式脑图铺满屏幕，「回到原文」弹出放大到段落的原文侧滑页；回忆模式遮住卡片内容。下文中「页边卡片」「右侧脑图」「收起脑图」等描述按此理解：页边卡片 = 窄边栏细条 + 卡片浮层；右侧脑图 = 脑图浮层或整理模式。设计：`design/layout-v2/layout-compare.html`（方案 D）。

> 设计依据：mNote 正式版设计稿「页边」（design-demos/final.html）中的底部四模式工具条「手写」组
> 测试素材：`test/samples/usecases/arxiv-2610.18579v1.pdf`（与 UC-01 相同）
> 设备：vivo Pad 6 Pro / iQOO Pad，横屏，**触控笔 + 手指**
> 前置：已按 UC-01 建好学习集并导入论文，至少有一张摘录卡片

## 1. 目标
用户在阅读论文时直接用笔在 PDF 页面上写字、画圈、划重点；笔迹属于这一页，跟着缩放和滚动走；可以擦除、撤销；可以用套索圈住一片笔迹（连同下面的原文）做成卡片放进脑图；最后能把带高亮和手写的 PDF 导出分享。

## 2. 约定
- **笔写、手指滚动**：默认只有触控笔能写，手指用来滚动和缩放。工具条上有「手指书写」开关，打开后手指用来书写、不再滚动页面；要滚动时关掉开关，或用笔写、手指滚。
- 笔迹坐标以 PDF 页面为准（单位：PDF 点），与屏幕大小、缩放无关；同一份笔迹在平板和手机上位置一致。
- 笔迹保存在学习集里，按文档、按页存放；不会写进原始 PDF 文件。
- 导出时把页面、高亮、手写合成为图片再生成新的 PDF（**扁平化**），原文在导出的 PDF 里不能再选中文字。

## 3. 主流程
| # | 用户操作 | 期望结果（验收点） |
|---|---|---|
| 1 | 打开论文，底部工具条点「手写」 | 工具组换成：钢笔、荧光笔、橡皮、套索，三档粗细，颜色，撤销、重做，「手指书写」开关；PDF 不再能长按选字 |
| 2 | 选钢笔，用笔在第 1 页摘要旁写几个字 | 笔迹跟随笔尖实时出现，粗细随压力变化；松开后笔迹留在页面上 |
| 3 | 用手指上下滑动 | PDF 正常滚动，不留下笔迹；笔迹跟着页面一起移动 |
| 4 | 双指放大到约 200% | 笔迹跟着放大，位置仍压在原来的文字上，边缘平滑 |
| 5 | 选荧光笔，划过摘要里的一行字 | 半透明荧光色压在文字上，文字仍清晰可读（不会被盖住变暗） |
| 6 | 点「撤销」两次，再点「重做」一次 | 依次撤掉荧光笔和钢笔的最后一笔，再恢复一笔 |
| 7 | 选橡皮，擦过钢笔笔迹 | 被碰到的整笔笔迹消失；摘录高亮不受影响 |
| 8 | 选套索，用笔圈住一片笔迹 | 被圈住的笔迹变色显示为选中；出现菜单：「摘录为卡片」「删除」「取消」 |
| 9 | 点「摘录为卡片」 | 生成一张图片卡片：图里是圈选范围内的原文和笔迹；卡片出现在页边同高处并进入脑图；点卡片能回到原文 |
| 10 | 退出 App 再打开该文档 | 所有笔迹都在原来的位置 |
| 11 | 顶栏「导出」 | 生成并分享一个 PDF：每页包含原页面、摘录高亮和手写；页数与原文相同 |

## 4. 分支与异常
| # | 情况 | 期望结果 |
|---|---|---|
| B1 | 打开「手指书写」后用一根手指写 | 能写；此时手指不再滚动页面；关闭开关后恢复滚动 |
| B2 | 一笔从第 1 页底部画到第 2 页 | 这一笔属于起笔所在的第 1 页，超出页面的部分照常显示；不会崩溃 |
| B3 | 在「手写」模式下点页边卡片、脑图节点 | 照常打开卡片 / 回到原文，不受影响 |
| B4 | 夜读模式下书写 | 笔迹颜色随反色显示，仍清晰可辨 |
| B5 | 套索没有圈到任何笔迹 | 不出菜单或提示「没有选中笔迹」 |
| B6 | 一页上写了几百笔 | 滚动仍然流畅，无明显卡顿 |
| B7 | 切回「摘录」模式 | 又能长按选字；笔迹仍显示 |

## 5. 非功能验收
- 落笔到笔迹出现的延迟肉眼不可察（目标 ≤ 1 帧额外延迟）。
- 33 页论文每页 50 笔时，滚动保持流畅。
- 导出 33 页论文 ≤ 30 秒，导出文件 ≤ 60 MB。

## 6. 不在本用例范围
笔迹转文字、形状识别、手写写进原 PDF 文件（可被其他阅读器编辑的批注）、多人协作。

## 7. 自动化测试映射（实现时补）
- 单元测试：屏幕坐标 ↔ PDF 页面坐标换算；笔迹序列化往返；橡皮命中；套索命中比例；撤销/重做栈。
- Widget 测试：手写模式下触控笔事件生成笔迹、手指事件不生成；手指书写开关。
- 集成：导出 PDF 的页数和页面尺寸与原文一致。
