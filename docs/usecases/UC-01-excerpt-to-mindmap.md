# UC-01 从 PDF 摘录到脑图（M1 核心用例）

> 设计依据：mNote 正式版设计稿「页边」（design-demos/final.html）
> 测试素材：`test/samples/usecases/cognitive-psych-ch6-sample.pdf`（自编示例教材，3 页 A4，可选中文字）
> 设备：vivo Pad 6 Pro / iQOO Pad，横屏（逻辑分辨率约 1280×800 dp），手指 + 触控笔

## 1. 目标
用户把一本 PDF 教材导入学习集，边读边把关键句摘录成卡片；卡片出现在原文同高的页边，同时进入右侧脑图，点卡片能回到原文。这是 MarginNote 用户最核心、每天重复最多的操作。

## 2. 角色与前置条件
- 角色：备考学生小林，熟悉 MarginNote。
- 前置：mNote 已安装（`io.github.cnwuzhh.mnote`）；设备里有测试 PDF；无需登录 Nextcloud（本用例全部本地完成）。

## 3. 主流程
| # | 用户操作 | 期望结果（验收点） |
|---|---|---|
| 1 | 书架点「新建学习集」，命名「认知心理学 · 记忆」 | 书架出现该学习集，待复习 0，文档 0 |
| 2 | 学习集内点「导入 PDF」，选择测试 PDF | 学习集显示 1 份文档、3 页；自动创建同名脑图，只有根节点「认知心理学 · 记忆」 |
| 3 | 打开文档 | 进入工作区：左版心、页边栏、右常驻脑图三栏；底部工具条默认「摘录」模式；顶栏显示「第 1 / 3 页」 |
| 4 | 连续向下滚动到第 2 页「6.3 间隔效应与提取练习」 | 连续滚动不分页跳动；页码更新为「第 2 / 3 页」；阅读进度百分比增加 |
| 5 | 长按选中「在总学习时间相同的条件下……更好的长期保持。」 | 选区可拖动两端调整；选区上方弹出摘录菜单：四色（黄/蓝/绿/红）、摘录为卡片、仅高亮、复制；菜单不遮挡选区 |
| 6 | 选「黄（定义）」，点「摘录为卡片」 | ① 原文出现黄色高亮；② 页边栏在同一高度出现卡片：标题默认取选中文字前若干字、黄色点、「p.2」；③ 卡片飞入右侧脑图并挂在根节点下，新节点闪一下；④ 页边卡片与高亮间有细引线 |
| 7 | 在脑图中把新卡片标题改为「间隔效应」 | 页边卡片标题同步更新 |
| 8 | 同样摘录「一周后……多记住约 50% 的内容」，选「蓝（实验证据）」 | 第二张卡片出现在其原文同高处，两张卡片按纵向位置排列、互不重叠 |
| 9 | 在脑图中把第二张卡片拖到「间隔效应」下作为子卡片 | 脑图层级更新；拖动时有插入位置提示 |
| 10 | 滚回第 1 页，再点脑图里的「间隔效应」卡片上的「回到原文」 | 版心滚动定位到第 2 页对应段落，高亮闪烁一次 |
| 11 | 点页边栏卡片 | 打开卡片详情：标题、原文、出处「认知心理学导论（示例）· 第 2 页」、批注区、标签、子卡片 1 张 |
| 12 | 退出 App 并重新打开该文档 | 高亮、卡片、脑图结构、阅读位置全部保留 |

## 4. 分支与异常
| # | 情况 | 期望结果 |
|---|---|---|
| A1 | 选「仅高亮」 | 只有高亮，不生成卡片、不进脑图 |
| A2 | 选中文字跨越第 2、3 页 | 允许摘录为一张卡片；出处记为起始页「p.2–3」 |
| A3 | 框选「图 6-4」区域（工具条选「框选」） | 生成图片卡片（区域截图），同样挂入脑图并可回到原文 |
| A4 | 删除一张卡片 | 对应高亮一并移除（或询问是否保留高亮）；可撤销 |
| A5 | 收起右侧脑图 | 版心变宽，页边卡片仍与原文同高 |
| A6 | 横竖屏切换 | 竖屏时脑图改为抽屉/底部面板，卡片与高亮不丢失 |
| A7 | 导入扫描版 PDF（无文字层） | 文字选择不可用时提示改用「框选」，不崩溃 |
| A8 | 切换深色主题 | 高亮四色仍可辨，页面与卡片文字对比度达标 |

## 5. 非功能验收
- 在测试设备上，摘录到卡片出现在页边 ≤ 300 ms，飞入动画约 0.7 s，滚动保持 60 fps 无明显掉帧。
- 3 页测试 PDF 打开 ≤ 1 s；后续用 300 页以上教材再测一次。
- 数据仅存本地；同步留到以后的里程碑。

## 6. 不在本用例范围
复习（FSRS）、回忆模式遮挡、手写批注、Nextcloud 同步、EPUB——分别属于 M3/M4 或以后。

## 7. 自动化测试映射（实现时补）
- Widget 测试：摘录菜单出现位置、页边卡片与选区同高（误差 ≤ 8 dp）、删除卡片同步移除高亮。
- 集成测试：用测试 PDF 跑通步骤 2–12。
