# UC-01 从 PDF 摘录到脑图（M1 核心用例）

> **布局更新（v2，2026-11-26）**：工作区不再是三栏。阅读（摘录 / 手写）时 PDF 占满宽度，右侧只有窄边栏（卡片数、卡片 / 脑图入口、与原文同高的彩色细条，可收起成把手）；卡片列表和脑图都以浮层从右侧拉出，盖在 PDF 上，PDF 不移动；摘录后选区旁显示「已加入：标题　编辑　撤销」，卡片飞入窄边栏。整理模式脑图铺满屏幕，「回到原文」弹出放大到段落的原文侧滑页；回忆模式遮住卡片内容。下文中「页边卡片」「右侧脑图」「收起脑图」等描述按此理解：页边卡片 = 窄边栏细条 + 卡片浮层；右侧脑图 = 脑图浮层或整理模式。设计：`design/layout-v2/layout-compare.html`（方案 D）。

> 设计依据：mNote 正式版设计稿「页边」（design-demos/final.html）
> 测试素材：`test/samples/usecases/arxiv-2610.18579v1.pdf`
> ——Li, Krishnan, Padman, *Reading Right, Acting Wrong: Diagnosing Decision Failures of System One Models in Agent Loops*, arXiv:2610.18579v1, CC BY 4.0（33 页，英文，**双栏排版**，带 PDF 目录书签、图表和公式符号）
> 设备：vivo Pad 6 Pro / iQOO Pad，横屏（逻辑分辨率约 1280×800 dp），手指 + 触控笔

## 1. 目标
用户把一篇论文导入学习集，边读边把关键句摘录成卡片；卡片出现在原文同高的页边，同时进入右侧脑图，点卡片能回到原文。这是 MarginNote 用户最核心、每天重复最多的操作。

这篇论文特意选来覆盖真实 PDF 的难点：双栏（选区不能串栏）、行尾连字符断词（如 `ac-`/`tion`）、跨页段落、图表、下标式记号（U1D0）、33 页长度与目录书签。

## 2. 角色与前置条件
- 角色：研究生小林，熟悉 MarginNote，要精读这篇论文准备组会。
- 前置：mNote 已安装（`io.github.cnwuzhh.mnote`）；平板里有测试 PDF；无需登录 Nextcloud（全部本地完成）。

## 3. 颜色约定（与设计稿一致）
黄＝定义　蓝＝实验证据　绿＝应用/方法　红＝易错

## 4. 主流程
| # | 用户操作 | 期望结果（验收点） |
|---|---|---|
| 1 | 书架点「新建学习集」，命名「Agent 决策失败」 | 书架出现该学习集，待复习 0，文档 0 |
| 2 | 学习集内点「导入 PDF」，选择测试 PDF | 显示 1 份文档、33 页、标题取自 PDF 元数据或首页；自动创建同名脑图，只有根节点 |
| 3 | 打开文档 | 三栏工作区：左版心、页边栏、右常驻脑图；底部工具条默认「摘录」；顶栏「第 1 / 33 页」 |
| 4 | 第 1 页摘要（左栏），选中 “System One models choose an agent’s next action by scoring a supplied set of options in a single pass.” | 选区只在左栏内，不串到右栏；两端可拖动调整；上方弹出摘录菜单（四色、摘录为卡片、仅高亮、复制），不遮挡选区 |
| 5 | 选「黄（定义）」→「摘录为卡片」 | ① 黄色高亮；② 页边同高出现卡片，标题默认取选中文字开头、黄点、「p.1」；③ 卡片飞入右侧脑图挂在根节点下，新节点闪一下；④ 页边卡片与高亮间有细引线；⑤ 卡片正文去掉 PDF 换行与 `ac-`/`tion` 式连字符，是一句连续的话 |
| 6 | 在脑图中把卡片标题改为「System One 模型」 | 页边卡片标题同步 |
| 7 | 打开目录（顶栏目录按钮），点「2 Measuring Comprehension and Decision…」 | 显示 PDF 书签目录（含二级标题）；跳到第 2 页对应位置 |
| 8 | 第 2 页右栏，选中 “For the six most accurate systems, 73–85% of decision errors occur on states where every measured fact is answered correctly, and the share grows with accuracy (§5.1).” → 蓝（实验证据）→ 摘录为卡片 | 卡片出现在原文同高处，与已有卡片按纵向位置排列、互不重叠；「73–85%」「§5.1」字符正确无乱码 |
| 9 | 用工具条「框选」框住第 2 页顶部的 Figure 1 | 生成图片卡片（区域截图，含图注），挂入脑图，可回到原文 |
| 10 | 第 3 页 §2.3，选中 “U1D0 does not show that the failure lies purely in deciding, and U0D1 does not show a shortcut.” → 红（易错）→ 摘录为卡片 | 卡片正常生成；记号 U1D0 / U0D1 文本可读（下标位置差异可接受，但字符不丢失） |
| 11 | 在脑图中把 Figure 1 卡片和第 8 步的证据卡片拖到「System One 模型」下 | 层级更新；拖动时有插入位置提示 |
| 12 | 用搜索（顶栏放大镜）查 “probe-then-decide” | 列出命中页 13、20，点第一条跳到第 13 页并高亮命中词 |
| 13 | 在第 13 页把命中所在句摘录为绿（方法）卡片 | 同上，卡片挂入脑图 |
| 14 | 滚回第 1 页，点脑图里第 10 步红色卡片的「回到原文」 | 版心定位到第 3 页对应句子，高亮闪烁一次 |
| 15 | 点页边栏任一卡片 | 打开卡片详情：标题、原文（或截图）、出处「Reading Right, Acting Wrong · 第 N 页」、批注区、标签、子卡片 |
| 16 | 退出 App 再打开该文档 | 高亮、卡片、脑图结构、阅读位置全部保留 |

## 5. 分支与异常
| # | 情况 | 期望结果 |
|---|---|---|
| A1 | 选「仅高亮」 | 只有高亮，不生成卡片、不进脑图 |
| A2 | 选中跨栏或跨页的一段（如第 1 页左栏底到右栏顶的 Introduction 段） | 选区按阅读顺序连续，不包含页眉页脚；摘录为一张卡片，出处记起始页 |
| A3 | 在第 2 页 Figure 1 上尝试长按选字 | 图中可选文字可选；不能选时提示改用「框选」 |
| A4 | 删除一张卡片 | 对应高亮一并移除（或询问是否保留高亮）；可撤销 |
| A5 | 收起右侧脑图 | 版心变宽，页边卡片仍与原文同高 |
| A6 | 横竖屏切换 | 竖屏时脑图改为抽屉/底部面板，卡片与高亮不丢失 |
| A7 | 双指缩放到 200% 阅读双栏 | 页边卡片仍与原文同高，引线跟随 |
| A8 | 切换深色主题 | PDF 页面可选反色/护眼底；高亮四色仍可辨，文字对比度达标 |

## 6. 非功能验收
- 摘录到卡片出现在页边 ≤ 300 ms，飞入动画约 0.7 s。
- 33 页论文打开首屏 ≤ 1.5 s；连续滚动全篇保持 60 fps，无白页闪烁。
- 全文搜索 ≤ 1 s。
- 数据仅存本地；同步留到以后的里程碑。

## 7. 不在本用例范围
复习（FSRS）、回忆模式遮挡、手写批注、Nextcloud 同步、EPUB、AI 生成目录——分别属于 M3/M4 或以后。

## 8. 自动化测试映射（实现时补）
- 单元测试：摘录文本清洗（合并换行、去连字符断词、保留 “73–85%”“§5.1”）。
- Widget 测试：摘录菜单位置、页边卡片与选区同高（误差 ≤ 8 dp）、删除卡片同步移除高亮。
- 集成测试：用测试 PDF 跑通第 2–16 步。
