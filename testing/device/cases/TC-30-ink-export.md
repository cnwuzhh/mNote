# PDF 手写批注（对应 UC-02）

前置：已完成 TC-SET-01、TC-SET-02（学习集里有论文），横屏，在工作区第 1 页。
**笔和手指的区分**：
- 触控笔：`adb shell input stylus swipe X1 Y1 X2 Y2 <毫秒>`（单击 `input stylus tap X Y`）。adb 注入的笔事件没有压力变化，粗细会是固定值，这是正常的。
- 手指：`adb shell input touchscreen swipe X1 Y1 X2 Y2 <毫秒>`。
- 有真实触控笔时，压力相关的步骤用真笔再测一次，并在结果里注明。
画曲线可以连续发几段短 swipe（每段 100–200 ms），或用 `sendevent`；画直线一段 swipe 即可。
