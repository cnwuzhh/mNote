# 脑图节点拖动（整理模式 / 脑图浮层）

前置：已完成 TC-SET-01、TC-SET-02，横屏。用 TC-MAP-SETUP 准备 5 张卡片。
节点上显示的是卡片标题（`text`），用 `uiautomator dump` 按标题找节点的 bounds；每个卡片节点右侧有回到原文图标（content-desc「回到原文 p.N」），**拖动时按住节点的标题文字部分，不要按这个图标**。

**怎么用 adb 拖节点**：节点要先按住不动约 0.5 秒才会被拿起，`input swipe` 一开始就移动，拖不动节点。请用 motionevent：
```bash
drag() {  # drag X1 Y1 X2 Y2
  adb shell input motionevent DOWN $1 $2; sleep 1
  for i in 1 2 3 4 5 6 7 8; do
    adb shell input motionevent MOVE $(( $1 + ($3-$1)*i/8 )) $(( $2 + ($4-$2)*i/8 )); sleep 0.08
  done
  sleep 0.4; adb shell input motionevent UP $3 $4
}
```
（Android 11 以下没有 motionevent 时用 `adb shell input draganddrop X1 Y1 X2 Y2 1500`。）每次拖动后等 1 秒再 dump，节点位置会随树的重排变化。

**怎么判断层级**：看截图里的连线——子节点在父节点右侧，用曲线与父节点相连；同一父节点的子节点上下排列。也可以对照 dump 里节点的 x 坐标：层级越深 x 越大。

## TC-MAP-SETUP 准备 5 张卡片（不是用例，只是准备）
在「摘录」模式下摘录 5 张卡片（标题可在卡片详情里改成下面的短名字，方便查找；中文输入不便时用括号里的英文名）：

| 名字 | 来源 | 颜色 |
|---|---|---|
| 卡A（CardA） | 第 1 页 Abstract 第一句 | 黄 |
| 卡B（CardB） | 第 1 页 `most wrong actions follow correct reading` | 蓝 |
| 卡C（CardC） | 第 1 页 `what is missing is often not a fact but the next sub-goal` | 绿 |
| 卡D（CardD） | 第 2 页 Figure 1（框选） | 黄 |
| 卡E（CardE） | 第 3 页 `U1D0 does not show …` 一句 | 红 |

然后切换模式 →「整理」：期望 5 张卡片都直接挂在根节点下（第一层）。
