# 从网络链接导入 PDF

前置：TC-SET-01 完成（有一个学习集）。**平板需要能上网**（先在浏览器里打开 https://arxiv.org 确认）。横屏。
输入链接：点输入框后用 `adb shell input text '<链接>'`（链接里有 `&` 时写成 `\&`）。
入口：学习集页右下角「导入 PDF」→ 底部弹出两个选项「从本机选择」「从网络链接」。

## TC-URL-01 arXiv 论文页链接　`冒烟`　P0
| # | 操作 | 期望 |
|---|---|---|
| 1 | 「导入 PDF」→「从网络链接」 | 弹出「从网络链接导入」对话框，输入框下方提示「arXiv 论文页的链接会自动换成 PDF」 |
| 2 | 输入 `https://arxiv.org/abs/2610.18579v1`，点「下载」 | 出现「正在下载」对话框：显示 `arxiv.org`、进度条和「已下载 x / y MB」、「取消」按钮 |
| 3 | 等待完成 | 自动打开阅读工作区，显示论文第 1 页，「第 1 / 33 页」 |
| 4 | 返回学习集页 | 文档列表里新增一项，标题 `2610.18579v1`（服务器给的文件名），副标题有「33 页」，第二行「来自 arxiv.org/pdf/2610.18579v1」 |
| 5 | 查看日志 | 无 Flutter 异常 |

|---|---|---|

## TC-URL-04 格式不对的链接　P1
| # | 操作 | 期望 |
|---|---|---|
| 1 | 输入框留空点「下载」 | 输入框下方红字「请输入链接」，对话框不关闭 |
| 2 | 输入 `ftp://example.com/a.pdf`，点「下载」 | 红字「只支持 http 或 https 链接」，不开始下载 |
| 3 | 点「取消」 | 对话框关闭，什么都不导入 |

## TC-URL-05 连不上的地址　P1
| # | 操作 | 期望 |
|---|---|---|
| 1 | 输入 `https://no-such-host.mnote.invalid/paper.pdf`，点「下载」 | 「无法导入」对话框，内容以「无法连接到 no-such-host.mnote.invalid」开头 |
| 2 | 输入 `https://arxiv.org/pdf/0000.00000v1`（不存在的论文） | 「无法导入」，内容含「服务器返回错误」和状态码（如 404）；**记录**实际内容 |
| 3 | 以上两步后 | 文档列表没有新增；App 不崩溃 |

## TC-URL-06 下载中取消　P1
| # | 操作 | 期望 |
|---|---|---|
| 1 | 输入 TC-URL-01 的链接，出现「正在下载」后**立即**点「取消」 | 对话框关闭，底部提示「已取消下载」；文档列表没有新增 |
| 2 | 如果点「取消」前下载已经完成（文件较小、网速快） | **记录**这一情况，不算失败；可以改用较大的 PDF 链接重试 |
| 3 | debug 包：`adb shell run-as io.github.cnwuzhh.mnote ls cache/mnote-downloads` | 没有残留的 `.part` 文件（目录不存在或为空） |

## TC-URL-07 导入后可改标题，重启后保留　P1
