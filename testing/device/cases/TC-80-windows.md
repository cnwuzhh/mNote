# Windows 版（第一档：能装、能跑）

适用：用鼠标的 Windows 10/11 笔记本或台式机（x64）。编译产物在 `~/projects/mNote/builds/mNote-Windows-<版本>-<提交>/`（由 GitHub Actions 编译，`scripts/mnote_windows_fetch.sh` 下载）。
第一档只保证功能可用；鼠标操作、窗口大小、快捷键等电脑上的体验问题属于第二档，**发现了请记录，不算失败**（除非功能用不了）。

## TC-WIN-01 安装与启动　`冒烟`　P0
| # | 操作 | 期望 |
|---|---|---|
| 1 | 双击 `*-installer.exe` | SmartScreen 提示「Windows 已保护你的电脑」（未签名，正常）→「更多信息」→「仍要运行」；安装向导标题为 mNote |
| 2 | 按默认安装，勾选「启动 mNote」 | 程序启动；窗口标题「mNote」；任务栏图标是黄色纸片上的花体 m |
| 3 | 若提示缺少 VCRUNTIME / MSVCP 之类的 DLL | 重新运行安装程序并勾选安装 Visual C++ 运行库（记录此情况） |
| 4 | 把窗口拖小 | 不能小于约 1024×700 |
| 5 | 「开始」菜单里有「mNote」；「设置 → 应用」里显示 mNote（发布者 cnwuzhh） | — |

## TC-WIN-03 学习集、导入、摘录（鼠标）　P0
| # | 操作 | 期望 |
|---|---|---|
| 1 | 新建学习集，「导入 PDF」→「从本机选择」，选 `arxiv-2610.18579v1.pdf` | Windows 文件对话框打开；导入后进入阅读界面，「第 1 / 33 页」 |
| 2 | 滚轮上下滚动 | 页面滚动，页码变化 |
| 3 | 鼠标从 Abstract 第一句开头拖到 `single pass.` | 选中文字，出现摘录菜单（如果拖动变成了滚动、选不了文字，**记录**） |
| 4 | 选黄色 →「摘录为卡片」 | 高亮、窄边栏细条、「已加入」提示，同平板 |
| 5 | 「从网络链接」导入 `https://arxiv.org/abs/2610.18579v1` | 能下载并打开（需要能上网） |

## 已知（第一档不处理）
- 安装包未签名，首次运行有 SmartScreen 提示。
- 界面按平板设计：脑图节点要长按约 0.5 秒才能拖动；没有快捷键和右键菜单；滚轮滚动不会进入沉浸阅读。
- 安装包里带有 Saber 原有的崩溃上报库（sentry.dll），但崩溃上报已关闭，不会发送任何数据。
