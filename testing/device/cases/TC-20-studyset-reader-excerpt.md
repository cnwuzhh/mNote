# 学习集、阅读、摘录（对应 UC-01，布局 v2）

素材：`assets/arxiv-2610.18579v1.pdf`（33 页、英文、双栏），已 push 到 `/sdcard/Download/`。
参考截图（1280×800，三张卡片时）：`reference/workspace_day.png`（阅读）、`workspace_cards.png`（卡片浮层）、`workspace_map.png`（脑图浮层）、`workspace_organize.png`（整理 + 原文侧滑页）、`workspace_recall.png`（回忆）、`workspace_night.png`、`workspace_handwrite.png`。
本组用例按顺序执行，后面的用例依赖前面创建的学习集和卡片。全部横屏（TC-UI-02 除外）。

**布局 v2 里的几个名字**（找元素用）
- **窄边栏**：屏幕最右侧约 44 dp 宽的竖条。顶部是卡片数（数字）和「卡片」二字，下面是两个图标按钮（content-desc「卡片」「脑图」），底部是「收起边栏」按钮；中间在与原文同高的位置画着彩色细条（卡片颜色），细条没有文字，需要看截图。
- **卡片浮层 / 脑图浮层**：从窄边栏拉出、盖在 PDF 右侧的面板。顶部有「卡片」「脑图」两个切换按钮、一行说明（如「本文 3 张」），以及「收起」按钮（content-desc「收起」）。
- **切换模式**：底部工具条最左边的深色按钮显示当前模式（如「摘录」，content-desc「切换模式」），点它弹出菜单「摘录 / 手写 / 整理 / 回忆」。
- 打开浮层、收起窄边栏时，**PDF 的位置和大小都不变**（可比较前后截图）。

## TC-EXC-01 摘录为卡片（黄・定义）　`冒烟`　P0
| # | 操作 | 期望 |
|---|---|---|
| 1 | 滚回第 1 页。在左栏 Abstract 里长按单词 `System`（第一句开头） | 出现文字选区和两端手柄 |
| 2 | 拖动结束手柄到第三行末尾的 `single pass.` | 选区覆盖整句，**只在左栏内**，不会跑到右栏 |
| 3 | 松手 | 选区上方弹出深色菜单：四个颜色圆点、「摘录为卡片」「仅高亮」「复制」；菜单不挡住选区 |
| 4 | 点黄色圆点（提示「定义」），再点「摘录为卡片」 | ① 这句话出现黄色高亮；② 选区附近出现一行「已加入：<标题>」，带「编辑」「撤销」，约 3 秒后消失；③ 窄边栏上**与这句话同高**出现一条黄色细条，卡片数变为 `1` |
| 5 | 点窄边栏的「卡片」按钮 | 卡片浮层从右侧盖在 PDF 上（PDF 不动），里面有这张卡片，**和原文大致同高**，标题是这句话开头几个词，下方「● 定义　p.1」 |
| 6 | 点这张卡片 | 右侧滑出卡片详情；原文框里是**连续的一句话**，以 `System One models choose an agent’s next action by scoring a supplied set of options in a single pass` 开头——没有换行，`action` 是完整的一个词（不是 `ac-tion` / `ac tion`），也没有乱码字符。**句末标点是否包含不检查**（见 KNOWN_ISSUES.md） |
