# 安装、品牌、首页、登录

## TC-INST-01 安装并启动　`冒烟`　P0
**前置**：已卸载旧版。
| # | 操作 | 期望 |
|---|---|---|
| 1 | `adb install -r <apk>` | 输出 `Success` |
| 2 | `adb shell dumpsys package io.github.cnwuzhh.mnote \| grep versionName` | 与 `manifest.json` 的 `versionName` 一致 |
| 3 | 在桌面找到 App | 名字显示为「mNote」；图标是黄色纸片上手写的「m」 |

| 5 | 查看日志 | 无 Flutter 异常 |

## TC-BRAND-01 界面里没有 Saber 字样　`冒烟`　P0
**前置**：TC-INST-01 通过。系统语言为简体中文。
依次打开下面的每个界面，每到一个界面执行 `uiautomator dump`，在 `text` 和 `content-desc` 里搜索 `Saber`（不区分大小写）。
| # | 界面 | 期望 |
|---|---|---|
| 1 | 学习集 | 无 Saber |
| 2 | 底部导航「首页」（最近笔记） | 无 Saber |
| 3 | 「全部笔记」 | 无 Saber |
| 4 | 「设置」，从上往下滚到底，每屏 dump 一次 | 无 Saber；能看到「自定义 mNote 文件夹」「自动检查 mNote 更新」 |
| 5 | 设置里进入登录 / 账号页 | 无 Saber |
| 6 | 设置里点版本号打开「关于」对话框 | **只允许**出现一行「mNote（基于 Saber） 版权所有 © 2022-… Adil Hanney」（按 GPL 必须保留原作者署名）；没有「赞助」类按钮 |
另外：App 图标应为黄色纸片上手写的「m」（不再是 Saber 的「S」）。

## TC-BRAND-03 隐私政策等链接是占位地址　P1
mNote 还没有自己的隐私政策网页。为避免链到 Saber 的页面，这些链接故意指向不存在的 `*.mnote.invalid` 地址：**打不开才是对的**。
| # | 操作 | 期望 |
|---|---|---|
| 1 | 设置 → 点版本号打开「关于」→ 点「隐私政策」 | 浏览器打开 `https://privacy-policy.mnote.invalid/`，显示无法访问 / 找不到服务器；**不能**打开 saber.adil.hanney.org 或任何正常网页 |
| 2 | 登录页上「隐私政策」链接 | 同上 |
| 3 | 抓日志 | App 本身不崩溃 |

## TC-LOGIN-02 横屏弹出键盘不溢出　P1
**前置**：横屏。
| # | 操作 | 期望 |
|---|---|---|
| 1 | 进入登录页，点服务器地址输入框 | 软键盘弹出；页面可以上下滚动，输入框在键盘上方可见 |
| 2 | 截图并查看日志 | 界面上**没有**黄黑条纹；日志里**没有** `RenderFlex overflowed` |
| 3 | 在输入框上方的空白处按住，向下拖约 600 px（`adb shell input swipe X 300 X 900 400`，X 取页面中间） | 键盘收起 |
| 4 | 再点输入框弹出键盘，然后点页面上的空白处（不是输入框、不是按钮） | 键盘收起 |
