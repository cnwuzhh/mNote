# 阅读体验（对应 UC-03）

前置：TC-SET-01、TC-SET-02 完成（学习集里有 `arxiv-2610.18579v1`），横屏、日间主题。`PKG=io.github.cnwuzhh.mnote`。
**AI 用例需要平板能上网**，并先完成 TC-AI-SETUP。

## TC-AI-SETUP 导入 AI 配置（准备，不是用例）
配置文件含 API Key，**只在本机私密位置**：`/home/johnson/mnote-secrets/ai_providers.json`。不要复制到编译目录、results/ 或任何截图、日志里；结果里只记录 Key 的后 4 位。
1. `adb push /home/johnson/mnote-secrets/ai_providers.json /sdcard/Download/ai_providers.json`
2. 学习集列表页右上角「AI 服务」→「导入配置文件」→ 选 `ai_providers.json`。期望：提示「已导入 2 个 AI 服务」；列表有「腾讯 TokenHub · DeepSeek Flash」（标「默认」）和「火山方舟 · ark-code-latest」（标「备用」），Key 只显示「••••」加后 4 位。
3. **立刻删除平板上的副本**：`adb shell rm /sdcard/Download/ai_providers.json`
4. 在「AI 服务」页对两个服务分别点「测试连接」：期望都显示「可用 · x.x 秒 ·「…」」。记录耗时。

## TC-AI-01 划词翻译（标记方式）　`冒烟`　P0
前置：TC-AI-SETUP。
| # | 操作 | 期望 |
|---|---|---|
| 1 | 第 1 页 Abstract 选中 `Across seventeen fast systems … take this form.`（整句） | 菜单：四色 \| 摘录为卡片、仅高亮 \| 翻译、解释 \| 更多；「复制」在「更多」里 |
| 2 | 点「翻译」 | 句子出现淡淡的虚下划线；左右栏之间的空白处出现「译」标记（生成中带转圈）；结果面板在句子**上方**展开，文字逐字出现；**面板不挡住这句话** |
| 3 | 等待完成（记录从点击到出现第一个字、到完成的秒数） | 面板显示中文译文，下方「AI 生成 · 腾讯 TokenHub · DeepSeek Flash · 可能有误」；按钮「存为批注」「摘录为卡片（附译文）」「复制」「重新生成」「删除」 |
| 4 | 点页面别处（不拖动） | 面板收起，只剩「译」标记和虚下划线 |
| 5 | 点「译」标记 | 面板再次展开，**立刻**显示刚才的译文（不重新生成） |
| 6 | 点「摘录为卡片（附译文）」 | 生成卡片（窄边栏多一条细条）；打开卡片详情，批注以「【AI 译文】」开头 |
| 7 | force-stop 后重新打开文档 | 「译」标记和虚下划线还在；点开仍是同样的译文 |
